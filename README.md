A make.fun bounty entry: a program that writes the funniest one-line warning
label for a time machine (120 characters or fewer) to `/output/entry.txt`.

Run it with:

```sh
python3 -P -s main.py
```

The label:

> WARNING: Do not photograph the dinosaurs. The flash is why they never saw the meteor coming.
